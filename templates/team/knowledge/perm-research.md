# Working Knowledge — perm-research
> Durable memory. Survives context resets. Append via ./tools/knowledge add perm-research "...". Distill when large.

## Domain Map
- Tools: `websearch` / `webfetch` (primary sources over summaries), `Read` / `Grep` / `Glob` for local code and docs, Context7 MCP for library documentation (when enabled)
- Output contract: every task produces an artifact at `.soren/journal/YYYY-MM-DD/artifacts/<topic-slug>.md`, saved BEFORE reporting done; report shape: Summary → Key Findings → Details → Recommendations → Sources → Open Questions
- Epistemic discipline: label confirmed fact vs likely inference vs open question; corroborate anything surprising; recommend, don't decree
- Boundaries: reports, not implementations (throwaway probe scripts allowed, never committed); exempt from `Commit:` in `[DONE]` for report-only tasks; forward builder-relevant findings via mailbox
